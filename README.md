# 뢰신

신뢰 상단원 전용 거상 도우미입니다.

## 처음 설치 (이 파일 하나만 받으세요)

**[Roesin-Setup.exe 받기](https://github.com/ljg2as-hub/gersang-app/releases/latest/download/Roesin-Setup.exe)**

1. 위 링크를 눌러 Roesin-Setup.exe 를 받습니다.
2. 받은 Roesin-Setup.exe 를 더블클릭합니다. "Windows의 PC 보호" 창이 뜨면 [추가 정보] → [실행] 을 누릅니다.
3. 검은 창에서 질문이 나오면 Enter 를 누릅니다.
4. 끝나면 바탕화면에 **Roesin** 아이콘(노란 '뢰')이 생기고 뢰신이 열립니다. 잠금 화면에서 관리자에게 받은 상단원 열쇠를 넣으세요.

- 이 페이지의 초록색 [Code] → Download ZIP 은 이 설명만 들어 있어 쓰지 않습니다.
- 이미 쓰고 있다면 받을 필요 없습니다. 켜 두면 새 버전으로 저절로 바뀝니다.
- 바탕화면 아이콘을 지웠다면 같은 파일을 다시 실행하세요. 모아 둔 자료는 그대로 두고 아이콘만 다시 만듭니다.
